# The Correctable Lineage

A research and evaluation package for testing whether explicit identification and authority records improve sequential correction.

> **New readers:** begin with [`START-HERE.md`](START-HERE.md). It defines the current research object and the smallest authoritative reading path.

## Current research object

The primary hypothesis is:

> Explicit representation of identified content, typed authority, validity scope, evidence dependencies, and reopening conditions may reduce invalid authority transfer during sequential evidence updates.

A candidate commitment record is:

\[
C=(H,W,\Sigma,\Pi,\mathcal R,\Gamma),
\]

where:

- \(H\): claim or hypothesis;
- \(W\): typed epistemic or operational authority;
- \(\Sigma\): validity and action scope;
- \(\Pi\): provenance and shared evidence dependencies;
- \(\mathcal R\): reopening conditions;
- \(\Gamma\): required response when reopening occurs.

Decision authority remains separate and depends on a declared consequence or loss model \(\Lambda\).

The upstream identifiability mathematics is established literature substrate. The open question is whether this downstream bookkeeping changes correction behavior relative to method-faithful alternatives after complexity cost.

## Repository precedence

When documents appear to point in different directions, use this order:

1. `START-HERE.md` and its linked front-door documents define the current claim and research phase.
2. Benchmark specifications, implementations, results, and negative-result ledgers define the current synthetic evidence.
3. Evaluation materials define proposed external tests; they are not completed evidence.
4. Remaining documents preserve historical development, applications, stress tests, and broader hypotheses. They provide provenance and do not override the current claim boundary.
