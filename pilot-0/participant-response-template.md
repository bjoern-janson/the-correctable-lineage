# Pilot 0 Secondary Cross-Method Extraction Template

## Administration boundary

This form is not the participant's primary representation and must not be shown before the assigned method's native artifact and action recommendation are frozen for the current evidence stage.

The frozen native artifact is the primary evidence for reconstruction, spontaneous distinction preservation, and method-specific usability.

This form is a secondary cross-method extraction surface. Prefer completion by blinded independent coders. When a participant completes it, record whether seeing the shared categories changed, added, or removed anything from the frozen native response. Information first introduced by this form does not count as evidence that the assigned representation preserved it unaided.

## 1. Current conclusions

Extract each material conclusion from the frozen native artifact.

| ID | Conclusion | Current authority status | Native support level | Uncertainty or alternative |
|---|---|---|---:|---|
| | | | | |

Use one current authority status:

- supported;
- conditionally supported;
- unsupported-but-open;
- contradicted;
- unresolved.

**Unsupported-but-open** means the conclusion is not currently justified for belief or action, but the supplied evidence does not rule it out and a plausible future discrimination remains.

Use the support scale native to the assigned representation.

Do not force support values into a probability if the method does not require one.

Mark an item as absent rather than inferring it when the frozen artifact does not contain enough information.
