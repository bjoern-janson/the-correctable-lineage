# Core Evolution Policy

## Status

This document governs how representational distinctions are proposed, localized, promoted, absorbed, demoted, or removed within this repository.

It is a maintenance policy for the repository's representational vocabulary. It is not part of the primary scientific hypothesis, does not establish the value of any current primitive, and does not provide empirical support for the claim-contract representation.

Its governing principle is:

\[
\boxed{
\text{Use the weakest representation that preserves the behaviorally necessary distinctions.}
}
\]

This is the representational analogue of minimal belief revision.

---

## 1. Minimal ontology revision

For beliefs:

\[
\text{contradiction}
\rightarrow
\text{shallowest sufficient revision}
\rightarrow
\text{preserve unaffected structure}.
\]

For ontology:

\[
\text{application failure}
\rightarrow
\text{shallowest sufficient representational change}
\rightarrow
\text{preserve unaffected primitives}.
\]

The important trigger is repeated evidence that the existing ontology cannot preserve a behaviorally consequential distinction without distortion or excessive reconstruction.

A distinction is not entitled to core status merely because it is:

- elegant;
- intuitive;
- explanatory;
- suggestive across several domains;
- compatible with the existing framework.

\[
\boxed{
\text{Conceptual usefulness}
\not\Rightarrow
\text{core necessity}.
}
\]

Applications should first test whether the existing core is already sufficient.

---

## 2. Ontology-update cycle

A proposed distinction \(D\) may move through the following states:

\[
D_{\mathrm{candidate}}
\rightarrow
D_{\mathrm{local}}
\rightarrow
D_{\mathrm{core}}
\rightarrow
D_{\mathrm{local}}
\ \text{or}\
D_{\mathrm{external}}
\ \text{or}\
\varnothing.
\]

### Candidate

A distinction appears during interpretation, application, evaluation, or maintenance.

At this stage, it has exploratory usefulness only. It has no authority as a core primitive.

### Local

The distinction is retained within the application or document where it resolves a concrete problem.

The local record should state:

- what would be conflated without it;
- what behavioral or evaluative consequence follows from the conflation;
- why existing primitives are insufficient in that local setting;
- which external or mature concepts might already perform the same function.

### Core candidate

A local distinction becomes a candidate for promotion only when independent applications repeatedly require it and existing primitives cannot reproduce its function without distortion or excessive reconstruction cost.

### Core

A distinction may enter the core only after evidence supports recurrence, irreducibility, behavioral consequence, external recoverability, comparative necessity, and acceptable complexity cost.

### Demotion, absorption, or removal

A core distinction may later be reduced in authority if evidence shows that it is:

- reducible to an existing primitive;
- application-specific rather than cross-domain;
- already represented by mature external terminology;
- behaviorally inert;
- too costly relative to its benefit;
- dependent on inventor mediation;
- unsupported by independent use.

Ontology must not become a one-way ratchet.

---

## 3. Shallowest-failure test

Before proposing a new primitive, identify the shallowest sufficient failure level.

### Observation

Was relevant information absent or unavailable?

### Inference

Was an adequate representation used incorrectly?

### Mechanism

Did the update, scoring, or decision process fail despite adequate representation?

### Representation

Could the existing primitives not express a behaviorally necessary distinction?

### Interface

Did routing, documentation, terminology, or presentation obscure a distinction that the ontology could already express?

### Governance

Did incentives, authority, or control prevent the use or correction of an otherwise adequate representation?

A new primitive is justified only when the shallowest sufficient diagnosis is genuinely representational.

\[
\boxed{
\text{Misuse of an ontology is not evidence that the ontology is insufficient.}
}
\]

---

## 4. Promotion gates

A local distinction becomes a candidate core primitive only when it satisfies the following gates.

### Recurrence

The distinction appears independently in multiple applications rather than being repeatedly imported by the framework author.

### Irreducibility

Existing primitives cannot preserve the relevant distinction without conflation, hidden assumptions, or excessive reconstruction burden.

### Behavioral consequence

Representing the distinction changes predictions, decisions, correction behavior, adjudication, failure detection, or another declared consequential outcome.

### External recoverability

Independent users can recognize and apply the distinction without inventor mediation.

### Comparative necessity

Mature alternatives cannot reproduce the same function more cheaply using their native representations.

### Complexity justification

The cross-domain benefit exceeds the translation, bookkeeping, and coordination cost added by the primitive.

The promotion rule is:

\[
\boxed{
D_{\mathrm{local}}
\xrightarrow{
\substack{
\text{independent recurrence}\\
+\ \text{irreducibility}\\
+\ \text{behavioral consequence}\\
+\ \text{external discrimination}
}
}
D_{\mathrm{core}}.
}
\]

A primitive earns authority through repeated explanatory necessity, not conceptual attractiveness.

---

## 5. Promotion record

Each proposed promotion should carry a compact auditable record:

\[
P_D=(S,F,A,C,R),
\]

where:

- \(S\): source applications in which the distinction recurred;
- \(F\): failures produced by the existing ontology;
- \(A\): alternatives considered, including mature external concepts;
- \(C\): behavioral consequences of representing versus omitting it;
- \(R\): reopening, absorption, and demotion conditions.

The record should answer:

1. Where did the distinction recur independently?
2. What could not be expressed before?
3. What behavior changed when it was represented?
4. Why was a local subtype insufficient?
5. Which established vocabulary was considered?
6. What evidence would absorb, demote, or remove it?

A promotion without this record remains provisional.

---

## 6. Demotion and absorption

Promotion must remain reversible.

\[
D_{\mathrm{core}}
\xrightarrow{
\text{successful reduction or absorption}
}
D_{\mathrm{local}}
\quad\text{or}\quad
D_{\mathrm{external}}.
\]

A distinction should be demoted or absorbed when later evidence shows that another representation performs the same function with equal or lower cost, or when recurrence and behavioral necessity do not survive external use.

Demotion reduces current authority without erasing provenance.

A demoted distinction may move to:

- an application document;
- a historical vocabulary appendix;
- an external-method mapping;
- a deprecated-concepts ledger.

The correct operation is:

\[
\text{core authority}\downarrow
\]

without:

\[
\text{historical visibility}\downarrow 0.
\]

---

## 7. Separation of authorities

A disciplined repository-maintenance process does not establish the primary scientific claim.

\[
\boxed{
\text{repository uses a disciplined process}
\not\Rightarrow
\text{primary empirical claim is true}.
}
\]

This policy may prove useful even if the claim-contract representation is later:

- absorbed into a mature method;
- reduced to a domain-local application;
- retained only as a pedagogical synthesis;
- rejected as a distinct operational contribution.

Process authority and scientific authority remain separate.

---

## 8. Current process-level claim

The strongest currently supported process observation is:

> In recent internal development, candidate distinctions have sometimes been retained as application-level or interpretive objects rather than automatically promoted into the core.

This is evidence of restraint within those internal development episodes.

It does not establish:

- a reliable ontology-governance process;
- optimal promotion criteria;
- successful demotion behavior;
- external usability of this policy;
- resistance to future framework expansion.

The relevant longitudinal test is:

\[
\boxed{
\text{Does the repository repeatedly keep attractive distinctions local until independent recurrence earns promotion?}
}
\]

A functioning policy should eventually produce all three outcomes:

\[
\boxed{
\text{promotion},
\qquad
\text{continued localization},
\qquad
\text{demotion or absorption}.
}
\]

A policy that only prevents additions may be conservative without being corrigible. A policy that can admit and remove distinctions under external evidence provides a stronger correction path.

---

## 9. Maintenance rule

The complete maintenance principle is:

\[
\boxed{
\text{Revise beliefs only as deeply as evidence requires; revise ontology only as deeply as behaviorally consequential recurrence requires.}
}
\]

The retention rule is:

\[
\boxed{
\text{A primitive earns entry through repeated necessity and retains authority only while that necessity survives comparison and reuse.}
}
\]

This policy governs the maintenance of the repository's representational vocabulary. It does not enlarge the primary research claim.
