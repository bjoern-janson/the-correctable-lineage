## Frozen checks

- **PASS — balanced_hidden_failure_exposed**: A paid challenge should expose hidden fragility and improve expected deployment reward.
- **PASS — balanced_sensor_not_fetishized**: Conditional challenge-and-repair should outperform unconditional sensor use.
- **PASS — balanced_diagnosis_localized**: The challenge should distinguish hidden fragility from a robust interface rather than authorize universal revision.
- **PASS — rare_fragility_skepticism_bounded**: Low prior risk should not justify a costly universal challenge under the declared scalar objective.
- **PASS — expensive_audit_rejected**: An informative challenge should be rejected when its expected value is below cost.
- **PASS — short_horizon_rejected**: A challenge should be rejected when too little deployment remains to repay it.
- **PASS — uninformative_challenge_exposes_limit**: v0.2 should fail when the challenge interface preserves the hidden correlation it was meant to break.

## Interpretation boundary

A positive result supports only a bounded value-of-information claim: an agent can pay for a predeclared challenge that breaks a suspected training correlation, then conditionally deploy a predeclared sensor.

The benchmark remains describable through Bayesian decision theory, active experiment design, costly information acquisition, and partially observable control. It does not establish autonomous interface discovery.
